# Vow — Capacitor Native App Setup

Turn your single-file `Vow — Retention Tracker v3.html` into a native iOS and Android app using [Capacitor](https://capacitorjs.com/).

---

## Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Node.js | ≥ 18 | https://nodejs.org |
| npm | ≥ 9 | bundled with Node |
| Xcode | ≥ 15 | Mac App Store (iOS only) |
| Android Studio | ≥ 2023 | https://developer.android.com/studio |
| CocoaPods | latest | `sudo gem install cocoapods` (iOS only) |

---

## Project layout

```
vow/
├── Vow — Retention Tracker v3.html   ← your existing single-file app
├── package.json
├── capacitor.config.json
├── scripts/
│   └── build.js                      ← copies HTML → www/index.html
└── www/                              ← generated by build script (git-ignored)
    ├── index.html
    └── manifest.webmanifest
```

---

## Step 1 — Install dependencies

```bash
npm install
```

This installs `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`, and the notifications + status-bar plugins.

---

## Step 2 — Initialise Capacitor (first time only)

```bash
npx cap init "Vow" "com.yourcompany.vow" --web-dir www
```

> **Tip:** Replace `com.yourcompany.vow` with your own reverse-domain bundle ID before submitting to any app store.

---

## Step 3 — Add platforms (first time only)

```bash
npx cap add ios
npx cap add android
```

This creates `ios/` and `android/` directories with the full native project scaffolding.

---

## Step 4 — Build web assets

```bash
npm run build
```

This runs `scripts/build.js`, which:
- Copies `Vow — Retention Tracker v3.html` → `www/index.html`
- Injects the Capacitor bridge `<script>` tag
- Removes the blob-URL PWA manifest (Capacitor handles this natively)
- Writes `www/manifest.webmanifest`

---

## Step 5 — Sync to native projects

```bash
npx cap sync
```

Or use the combined shortcut:

```bash
npm run sync      # runs build + cap sync
```

Run this every time you edit the HTML file.

---

## Step 6 — Open native IDEs

**iOS (Xcode):**
```bash
npm run ios
# or: npx cap open ios
```

**Android (Android Studio):**
```bash
npm run android
# or: npx cap open android
```

## Step 7 — App icons & splash screens

Capacitor has an official assets generator. Provide one 1024×1024 PNG icon and one 2732×2732 PNG splash:

```bash
npm install --save-dev @capacitor/assets
npx capacitor-assets generate --iconBackgroundColor '#1A1A1C' --splashBackgroundColor '#1A1A1C'
```

Place your source files at:
```
assets/
├── icon-only.png        (1024×1024, the leaf-V logo, no padding)
├── icon-foreground.png  (1024×1024, adaptive icon foreground for Android)
├── icon-background.png  (1024×1024, solid #1A1A1C for adaptive icon background)
└── splash.png           (2732×2732, centered logo on dark background)
```

Full guide: https://capacitorjs.com/docs/guides/splash-screens-and-icons

## Step 8 — Build for release

### iOS
1. Open Xcode via `npx cap open ios`
2. Select your team in **Signing & Capabilities**
3. Set **Bundle Identifier** to `com.yourcompany.vow`
4. Choose **Any iOS Device** as the target
5. **Product → Archive**, then distribute via App Store Connect

### Android
1. Open Android Studio via `npx cap open android`
2. **Build → Generate Signed Bundle / APK**
3. Create or use an existing keystore
4. Upload the `.aab` to Google Play Console

## Changes needed in your `index.html`

Your app is already Capacitor-compatible. The build script handles most things automatically. Here's what to know:

### ✅ Nothing to rewrite

| Feature | Status |
|---------|--------|
| `localStorage` | Works natively in Capacitor WebView |
| `<canvas>` | Works natively |
| CSS animations / particles | Work natively |
| `document.visibilitychange` | Works natively |
| PWA manifest blob URL | **Removed by build script** (Capacitor uses native manifest) |

### ⚠️ Notifications — swap Web API for Capacitor plugin

Your app currently uses the browser `Notification` API. On iOS this does **not** work inside a Capacitor WebView. Replace it with `@capacitor/local-notifications`.

Add this near the top of your `<script>` block (after the Capacitor bridge loads):

```js
// Replace the browser Notification API with Capacitor Local Notifications
// Only runs inside Capacitor; falls back to Web API in a plain browser.
async function requestNativeNotifPermission() {
  if (!window.Capacitor) return Notification.requestPermission();
  const { LocalNotifications } = Capacitor.Plugins;
  const { display } = await LocalNotifications.checkPermissions();
  if (display !== 'granted') {
    const result = await LocalNotifications.requestPermissions();
    return result.display === 'granted' ? 'granted' : 'denied';
  }
  return 'granted';
}

async function sendNativeNotif(title, body) {
  if (!window.Capacitor) {
    new Notification(title, { body });
    return;
  }
  const { LocalNotifications } = Capacitor.Plugins;
  await LocalNotifications.schedule({
    notifications: [{
      title,
      body,
      id: Date.now(),
      schedule: { at: new Date(Date.now() + 500) },
      smallIcon: 'ic_stat_icon_config_sample',
      iconColor: '#3B8E5E',
    }]
  });
}
```

Then in your existing notification code replace:
- `Notification.requestPermission()` → `requestNativeNotifPermission()`
- `new Notification(title, {body})` → `sendNativeNotif(title, body)`

### ⚠️ Status bar colour (iOS notch)

The `capacitor.config.json` already sets `StatusBar.style = DARK` and `backgroundColor = #1A1A1C`. No HTML changes needed.

### ⚠️ Safe-area insets

Your CSS already uses `env(safe-area-inset-*)` correctly — nothing to change.

### ⚠️ `viewport-fit=cover`

Your `<meta name="viewport">` already includes `viewport-fit=cover` — nothing to change.

### ⚠️ External links

Any `<a href>` that opens an external URL will open inside the WebView. To force them into the device browser, add this once:

```js
document.addEventListener('click', e => {
  const a = e.target.closest('a[href]');
  if (a && a.href.startsWith('http') && !a.href.includes(window.location.host)) {
    e.preventDefault();
    if (window.Capacitor) Capacitor.Plugins.Browser?.open({ url: a.href });
    else window.open(a.href, '_blank');
  }
});
```
